# 📈 Stock Chart Visualization Agent (주식 차트 시각화 비서)

AI 에이전트와 대화하며 실시간 주식 데이터를 분석하고 인터랙티브한 차트를 생성하는 프로젝트입니다.

## 주요 기능
* **자연어 요청 처리:** "삼성전자 차트 그려줘"와 같은 일상어로 명령 가능
* **전문적인 차트 생성:** Candlestick, Line 차트 및 다양한 보조지표 지원
* **실시간 데이터:** `yfinance`를 통한 최신 주식 정보 반영

## 기술 스택 (Tech Stack)
* **Backend:** Python, FastAPI, LangGraph, LangChain
* **Frontend:** Streamlit
* **AI Model:** OpenAI GPT-4o
* **Monitoring:** LangSmith
